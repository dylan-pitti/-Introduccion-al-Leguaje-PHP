# Lab1 - Introducción a PHP
 
Repositorio para la entrega del Laboratorio: Introducción al Lenguaje PHP. Creado y desarrollado por Dylan Pitti del salón 1S3122
 
 
Es un laboratorio enfocado en los fundamentos de PHP como el POST y el uso de HTML, CSS y un poco de C como complemento
 
## Contenidos del Repositorio
 
| Archivo | Descripción |
|---|---|
| `edad.php` | Ejercicio para calcular o mostrar la edad a partir de datos ingresados por el usuario. |
| `calculadora.php` | Formulario HTML para ingresar dos números y seleccionar una operación (sumar, restar, multiplicar, redondear). |
| `pulg.php` / `pulgada.php` | Conversión de unidades (pulgadas a otras medidas). |
| `calc.php` | Procesa los datos enviados por `calculadora.php` e imprime los resultados. |
| `pagina2.php` | Página de ejemplo/complementaria dentro de la práctica. |
| `practica1.php` | Primer ejercicio  PHP. |
| `practica2.php` | Segundo ejercicio  PHP. |
| `practica3.php` | Tercer ejercicio  PHP. |
| `practica4.php` | Cuarto ejercicio PHP. |
| `practica4.c` | Práctica 4, pero realizada en C. |
| `pulgesti.css` | Hoja de estilos usada por los ejercicios de conversión de pulgadas. |
 
## Lenguajes Utilizados
 
- **PHP** 
- **HTML** 
- **CSS** 
- **C** 
##  Cómo ejecutar el proyecto
 
1. Clonar el repositorio:
```bash
   git clone https://github.com/gabrielmendoza-nht/Lab1-Introduccion-a-Php.git
```
2. Colocarlo dentro del directorio de tu servidor local (www si se usa WAMP o LAMP).
3. Iniciar Apache y PHP y después conectarse al servidor local mediante hhtp://127.1.1.1
4. Elegir el archivo a probar
